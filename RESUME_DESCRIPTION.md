# Resume Description

**Mafia's Word** - A multiplayer social deduction word game built with React and TypeScript. Developed a responsive web application supporting 2-25 players where participants receive a secret word while one randomly assigned "Mafia" player remains unaware. Implemented game state management using React Context API with session storage persistence, dynamic word selection from categorized pools, and a card-based reveal system with flip animations. Features include dark/light theme toggle, category filtering, responsive design with CSS Modules, and centralized string management for maintainability. Built with React Router for navigation, TypeScript for type safety, and modern React hooks for state management.
